This repository documents my journey and growth in competitive programming through problems solved on Codeforces. It serves as a record of my progress as I continuously challenge myself with increasingly difficult problems while developing stronger algorithmic thinking and problem-solving skills.

All solutions are stored in the `questions` folder, making this repository a straightforward archive of my progress. Each file represents a challenge overcome and another step forward in my learning journey.

The main reasons I am committed to maintaining this repository are:

* **Developing Better Intuition:** Codeforces problems often require creative thinking and mathematical insights before even writing the first line of code. I want to train my brain to recognize these patterns more naturally.
* **Learning New Concepts:** I want to gradually study and implement more advanced algorithms and data structures commonly used in competitive programming, such as graph theory, dynamic programming, and number theory.
* **Upsolving:** One of my main focuses is revisiting problems I could not solve during contests. I believe true growth comes from understanding my mistakes and eventually finding the correct solution.
* **Improving Under Pressure:** Participating in contests helps me develop the ability to analyze problems quickly, make efficient decisions, and write correct solutions within strict time limits.
* **Consistency:** Keeping this repository active serves as a personal journal of my dedication and helps me stay consistent, even when the problems become more challenging.

This repository is a continuous work in progress, driven by my interest in discovering different ways to approach algorithms, data structures, and competitive programming.
